Sessions

Three session layers, at four moments

The app session, Keycloak's SSO session and the tokens are separate things with separate lifetimes. Each column is a snapshot from this run: the browser's cookies, memes-web's memory, and Keycloak's admin API.

Learning goal 2

Four signed things, side by side

One login produced three tokens plus Keycloak's SSO cookie. They share a sub and a session id (sid 2Ckpo75D…, also the callback's session_state and the admin API's session). What separates them is who each one is for and who reads it.
